# Instructions for Claude

## Coding Style Rules

* Write code like a human developer
* Avoid over-engineering
* Do NOT create too many files
* Keep folder structure simple
* Avoid unnecessary abstraction layers
* Avoid excessive comments
* Use clear naming (not overly clever)

---

## Architecture Rules

* Use simple REST API
* Separate:

  * routes
  * controllers
  * models
* Keep logic readable

---

## Frontend Rules

* Use React with simple structure
* No over-complicated state management
* Use basic hooks (useState, useEffect)
* Clean UI, not fancy

---

## Backend Rules

* Node.js with Express
* Simple middleware
* JWT auth
* No complex patterns

---

## Database Rules

* Simple relational schema
* Clear table names
* Avoid premature optimization

---
